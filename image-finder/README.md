# Image Finder (standalone source)

This is the **original** standalone Image Finder app, copied here for reference.

The same feature is **integrated** in this project under **Admin → Flashcard Images** (`/admin/flashcard-images`). The live code lives in `client/src/pages/flashcard-images/` and `client/src/pages/admin/flashcard-images.tsx`.

You can run this folder standalone with `npm install` and `npm run dev` if you want to use it as a separate app.
