# Style example images

Add one image per style so the Flashcard Images page can show them in the style selector. Filenames (lowercase):

- `clipart.png`
- `cartoon.png`
- `animation.png`
- `vector.png`
- `comics.png`
- `realistic.png`

Use example images you generated earlier (one per style). If a file is missing, the label will show as fallback.
